## Migration trên Staging / Production

Hai máy CMS: `cms-sg-01` (`194.233.89.26`) và `cms-lss-01` (`169.58.47.30`). Đường dẫn `/opt/cms`. Không deploy `a1logex-sg-01` / `/opt/alogex`. Không ghi đè `infra/.env`.

`infra/docker-compose.host.yml` bật `Database__MigrateOnStartup=true`. API áp migration lúc khởi động. Sau deploy, kiểm tra trên Postgres của từng máy:

```sql
SELECT "MigrationId" FROM "__EFMigrationsHistory"
WHERE "MigrationId" LIKE '%RateRuleScopeWeightBand%';
```

Chỉ chạy tay khi cờ migrate bị tắt:

```bash
dotnet ef database update --project src/LCMS.Infrastructure --startup-project src/LCMS.Api
```

Không sửa migration đã phát hành. Không xóa bảng giá cũ: `Ac30` sao chép tuyến header sang rule và ghi `rate_scope_migration_logs`.
